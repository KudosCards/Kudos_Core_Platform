# Vendored print fonts

These `*.ttf` files are embedded by the server-side card→PDF engine
(`apps/api/src/print-pdf`, docs/adr/0162) so printed text is true vector in the
exact typeface the card editor offers.

- **Provenance / reproducibility:** generated by `../../../scripts/vendor_print_fonts.py`
  from the upstream [google/fonts](https://github.com/google/fonts) repository.
  Most families ship only variable fonts upstream, so real static Regular/Bold/
  Italic/BoldItalic weights are instantiated with fontTools' instancer.
- **Licences:** every family is OFL-1.1; the full licence text for each is in
  [`licenses/`](./licenses). The Open Font Licence permits bundling and
  redistribution with the software.
- `Gelasio-*` is a metric-compatible substitute for the "Georgia" editor key.
  The `Helvetica` / `Times New Roman` / `Courier New` keys are **not** vendored —
  the engine maps them to PDF's built-in standard families.

nest-cli copies this directory to `dist/print-pdf/fonts` on build (see
`nest-cli.json` `assets`), so the TTFs ship with the compiled API.
